# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common answers to questions you have while using Changesets in the [FAQ](https://github.com/changesets/changesets/blob/main/docs/FAQ.md).

## How do I add a changeset?

Run `yarn changeset` and answer the prompts. This creates a small Markdown file in `.changeset/` that describes the change.
Commit and push that file with your PR.

## When do I need a changeset?

Any PR that should produce a new version of the published package needs a changeset. Purely internal tooling or
documentation changes usually do not.

## What happens on `main`?

When a PR with one or more changesets is merged to `main`, a GitHub Action opens a **Version Packages** PR that
bumps `package.json` and updates `CHANGELOG.md`. Once a maintainer reviews and merges that PR, the same action
creates a Git tag, a GitHub Release, and publishes the new version to npm.
